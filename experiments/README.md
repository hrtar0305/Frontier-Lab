# experiments

Lab 글에 딸린 실험 코드를 두는 곳입니다. 사이트 빌드에는 포함되지 않습니다.

## 규칙

- 실험 하나에 폴더 하나: `experiments/<YYYY-MM-DD>-<영문-슬러그>/`
  Lab 글의 파일명과 같은 이름을 씁니다.
- 폴더마다 `README.md` 를 두고 실행 방법과 사용한 버전을 적습니다.
- Lab 글 frontmatter 의 `code:` 에 이 폴더 경로를 적으면 글에서 코드로 링크가 걸립니다.
- API 키 같은 비밀 값은 커밋하지 않습니다. `.env` 는 `.gitignore` 에 들어 있습니다.
- 큰 데이터나 모델 가중치는 올리지 않고, 받는 방법을 README 에 적습니다.
